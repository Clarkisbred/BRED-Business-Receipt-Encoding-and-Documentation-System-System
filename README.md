# BRED — Business Receipt Encoding and Documentation

## Overview

**BRED (Business Receipt Encoding and Documentation)** is a Java desktop application designed to securely encode, organize, search, and manage official business receipts and supplier transactions. It provides a centralized platform for maintaining digital receipt records, tracking purchases, managing project-related expenses, and generating transaction reports.

The system allows authorized users to encode receipt information, maintain supplier records, upload receipt attachments, and associate transactions with specific projects. Each receipt is stored in a searchable digital archive, making it easier to retrieve, review, and monitor business transactions.

BRED supports both local database storage and Supabase integration, providing flexible data storage options. It also incorporates role-based user accounts, activity logging, and customizable FlatLaf themes to provide a structured, secure, and user-friendly desktop experience.

## Key Features

- **Receipt Management** – Add, view, edit, delete, and organize encoded business receipts.
- **Detailed Receipt Records** – Maintain receipt numbers, transaction dates, TIN numbers, supplier information, purchased items, quantities, unit prices, and total amounts.
- **Product and Item Tracking** – Record individual purchased items, including descriptions, quantities, unit prices, and subtotals.
- **Supplier Management** – Maintain supplier information, including business names, addresses, contact details, and TIN numbers.
- **Project Management** – Associate receipts with specific projects to organize and monitor project-related purchases and expenses.
- **Search and Filtering** – Retrieve receipts using receipt numbers, TIN numbers, supplier names, product descriptions, dates, or project names.
- **Receipt Attachments** – Upload and manage scanned copies, photographs, and PDF versions of original receipts.
- **Expense Monitoring** – Track purchase amounts and expenses across different projects and suppliers.
- **Reports and Analytics** – Generate transaction reports and expense summaries based on dates, projects, suppliers, and other criteria.
- **Role-Based User Accounts** – Manage user accounts, roles, and access permissions to control system functionality.
- **Activity Logs** – Maintain records of receipt encoding, modifications, and other system activities.
- **Flexible Database Storage** – Support local database storage and Supabase integration.
- **Customizable Interface** – Utilize FlatLaf themes to provide different desktop appearance options.

## Receipt Information

Each encoded receipt can contain the following information:

| Category | Information |
|---|---|
| Receipt Details | Receipt Number, Receipt Date, Receipt Type |
| Supplier Details | Business Name, TIN, Address, Contact Number |
| Purchase Details | Item Description, Quantity, Unit Price, Subtotal |
| Financial Details | VAT, Discounts, Additional Charges, Grand Total |
| Project Details | Project Name, Project Code, Fund Source |
| Attachments | Original Receipt Image or PDF |
| Record Details | Encoded By, Date Created, Last Modified |

## Main Objective

The primary objective of BRED is to provide an organized, secure, and accessible digital recordkeeping system for official business receipts and supplier transactions.

Instead of relying on manually organized physical receipts and documents, the application allows users to encode, store, retrieve, and monitor transaction records through a centralized desktop platform.

BRED aims to improve receipt documentation, supplier record management, project expense monitoring, transaction tracking, and financial record accessibility while maintaining organized and accountable digital records.
